# 第 75 阶段：GPUI 诊断报告展示

本阶段在诊断运行完成后展示后端运行摘要中的 `final_answer`。报告面板只在状态为 `completed` 时出现。

## 展示规则

- 报告按纯文本逐行展示，不解析 Markdown，不执行链接、脚本或其他嵌入内容。
- 空报告不显示。
- 超过 12000 个字符的报告不显示，避免单次运行结果占用过多桌面端渲染资源。
- 非 `completed` 状态不显示报告，即使响应包含 `final_answer`。

报告内容仍来自后端已投影的运行摘要。桌面端不读取 Harness checkpoint、原始工具观察结果或模型上下文。

## 验证范围

Rust 测试覆盖空报告和超长报告的拒绝，以及有效报告的首尾留白处理。完整验收还包括 Rust 编译检查，以及 Python 服务端的测试、静态检查和类型检查。
