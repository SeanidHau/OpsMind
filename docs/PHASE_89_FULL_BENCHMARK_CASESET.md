# 第 89 阶段：完整端到端评测集

## 目标

本阶段新增 `data/evaluations/diagnosis_cases_full.json`，包含 50 条可由现有端到端基准命令加载的固定样本。

| 分组 | 数量 | 预期路径 |
| --- | ---: | --- |
| 订单、支付、库存、推荐核心故障变体 | 40 | 完成诊断并收集日志和指标证据 |
| 误导性假设 | 4 | 使用场景证据排除错误假设 |
| 信息不足 | 4 | 等待用户补充信息 |
| 知识缺口上下文 | 2 | 在缺少额外配置资料时使用现有场景证据完成诊断 |

所有根因关键词均来自内置模拟场景。样本不会将未实现的工具超时、真实基础设施故障或未提供的知识文档标记为已覆盖。

## 运行方法

配置 `LLM_PROVIDER` 后，显式运行完整评测集：

```bash
uv run python -m scripts.run_benchmark \
  --cases-file data/evaluations/diagnosis_cases_full.json \
  --fail-on-failure
```

该命令按样本顺序执行。完整评测会发起比烟雾样本更多的模型调用，并可能写入配置的运行归档。运行前确认模型额度、Milvus 和 PostgreSQL 配置符合预期。

## 结果解释

`passed` 表示每条样本的轨迹检查、预期终止状态、根因关键词和必需工具证据均已通过。它不是对模型诊断能力的绝对结论。记录结果时，应同时保存模型名称、提供商配置、样本文件版本和执行时间。
