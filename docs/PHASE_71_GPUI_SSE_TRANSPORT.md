# 第 71 阶段：GPUI SSE 传输层

桌面端客户端新增 `POST /api/v1/runs/stream`。请求包含 `session_id`、`thread_id` 和已校验的 `user_query`。传输层读取 HTTP 响应时按数据分块增量解析 SSE；收到完整事件后立即调用事件回调，不等待连接关闭。

SSE 解析器仅接受 JSON 对象数据。传输层限制单次 SSE 响应总量为 1 MiB。响应不是 UTF-8、事件数据不是 JSON 对象或响应超过上限时，客户端停止读取并返回错误。

传输层仍不决定界面展示字段。后续 GPUI 状态层只会从后端已经安全投影的事件中提取运行状态、步骤、工具名称和最终摘要，不会展示工具参数、原始工具观察结果或模型上下文。

本阶段包含分块解析和本地 HTTP POST/SSE 契约测试。下一阶段将把传输层连接到桌面端的实时轨迹面板。
