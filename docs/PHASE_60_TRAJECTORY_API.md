# 第 60 阶段：运行轨迹查询 API

本阶段提供 `GET /api/v1/runs/{run_id}/trajectory`，用于读取已归档诊断运行的安全时间线。

接口从缓存快照读取数据。请求不会重新调用模型、工具或 Harness 节点。响应包含运行 ID、回放模式、终止状态、事件数量和按记录顺序返回的事件。

## 公开字段

每个事件包含事件 ID、步骤 ID、事件类型、时间、节点、动作类型、工具名称、延迟、Token 用量、决议和错误信息。`action_type` 与 `tool_name` 在事件没有动作时返回 `null`。

接口不返回工具参数、工具原始观察结果、模型输入摘要或完整动作内容。这些内容可能包含凭据、业务数据或内部上下文。需要查看完整快照时，应在受控的内部诊断环境中读取归档数据。

## 错误处理

未知 `run_id` 返回 `404` 和 `run not found`。应用未配置运行查询能力时，接口返回 `503` 和 `diagnosis run reader is not configured`。
