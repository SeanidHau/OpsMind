# 第 87 阶段：RAG 检索质量门禁

## 目标

第 86 阶段的检索评测用于观察指标。本阶段为 CI 提供显式质量门禁，避免固定样本漏召回时构建仍显示成功。

## 使用方法

在已配置 Embedding 且已导入相同知识库的环境中执行：

```bash
uv run python -m scripts.evaluate_retrieval --fail-on-miss
```

命令始终先输出 JSON 评测结果。启用 `--fail-on-miss` 后，如果任一固定样本未在前 K 条结果中命中，进程以状态码 `1` 退出。全部样本命中时，进程以状态码 `0` 退出。

未启用该参数时，命令始终以状态码 `0` 完成。这种模式适合本地查看 `Recall@K`、`MRR` 和各样本排名，不会将评测结果作为构建门禁。

## 限制

门禁只判断固定样本是否命中预期 `source_id`。它不替代对知识内容、检索排序质量、诊断结论或来源引用完整性的人工审阅。
