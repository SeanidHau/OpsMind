# 第 69 阶段：GPUI 后端状态加载

GPUI 控制台启动后会在后台读取 `GET /api/v1/health` 和 `GET /api/v1/scenarios`。窗口先渲染加载状态。后台请求完成后，主线程更新连接状态和场景目录摘要数量，再触发界面重绘。

默认后端地址为 `http://127.0.0.1:8000`。可通过 `OPSMIND_API_BASE_URL` 指定其他 FastAPI 服务地址。地址应为服务根地址，不包含 `/api/v1`。

健康检查和场景目录均成功时，控制台显示 API 版本和场景摘要数量。任一请求失败时，控制台显示通用的服务不可用状态，不展示原始网络错误或响应内容。

本阶段新增成功与失败状态转换测试。下一阶段将接入故障描述输入和 `POST /api/v1/runs/stream`。
