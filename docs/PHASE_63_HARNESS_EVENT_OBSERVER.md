# 第 63 阶段：Harness 事件观察器

本阶段为 `HarnessLoop` 增加可选的 `HarnessEventObserver`。Harness 每次创建审计事件后，都会按创建顺序调用 `on_event`。

## 使用边界

观察器接收事件的深拷贝。观察器修改事件不会影响运行状态、轨迹、预算或归档快照。观察器抛出异常时，Harness 记录警告并继续执行诊断。

观察器是内部扩展点，不是 HTTP API。后续实时 SSE、LangSmith Trace 或其他监控适配器可以实现这个接口，将同一份事件流转发到各自的消费端。

## 当前限制

观察器在事件创建时同步调用。耗时或阻塞操作不应放在 `on_event` 中。实时推送适配器应只进行非阻塞入队，再由独立消费者处理网络 I/O。
