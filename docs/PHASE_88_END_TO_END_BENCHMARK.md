# 第 88 阶段：端到端诊断基准

## 目标

本阶段将已有的轨迹评测和业务断言连接到可提交的固定样本集。`data/evaluations/diagnosis_cases.json` 当前包含四条与内置模拟场景对应的样本。

每条样本声明用户问题、预期终止状态、可选根因关键词和必需证据工具。运行结果同时包含轨迹检查、根因检查和工具证据检查。

## 前置条件

配置可用的 `LLM_PROVIDER`。脚本使用当前模型、工具和可选 RAG 配置。配置 RAG 时，先导入同一知识目录。

## 使用方法

执行基准：

```bash
uv run python -m scripts.run_benchmark
```

命令输出 JSON 结果。每条样本使用独立的稳定会话和线程标识。未配置 RAG 时，脚本只注册模拟场景工具。

在 CI 中执行：

```bash
uv run python -m scripts.run_benchmark --fail-on-failure
```

启用 `--fail-on-failure` 后，任一样本未通过时，脚本先输出 JSON，再以状态码 `1` 退出。未启用该参数时，脚本以状态码 `0` 退出，适合本地观察结果。

## 限制

当前基准集只有四条核心场景样本，用于验证端到端执行链路。项目完成定义要求的更大样本集将在后续阶段补充。模型输出仍可能随模型版本或服务端配置变化，评测结果必须与所用配置一起记录。
