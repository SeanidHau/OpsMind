# 第 43 阶段：计划项级工具尝试预算

## 目标

为单个计划项增加工具尝试上限。全局工具预算限制整个运行，单工具预算限制某个工具，计划项预算限制为同一诊断目标反复尝试不同工具或重试所消耗的资源。

## 配置与计数

`PlanItem.max_tool_attempts` 默认值为 `None`，表示不设置上限。设置时，值必须大于零。

上限按绑定同一 `plan_item_id` 的 `TOOL_STARTED` 事件计数。因此首次执行、成功、失败和自动重试都会计入。未绑定计划项的工具调用不受本规则影响。

## 阻断

模型提出的新工具调用在预算消费前检查计划项上限。工具失败后的自动重试也会在下一次实际调用前检查该上限。

达到上限时，Harness 阻断动作，原因是 `plan item tool attempt limit is reached`，并在重试事件观察中记录 `plan:tool_attempt_limit`。

## 模型上下文

Context Manager 在计划条目中输出 `max_tool_attempts`，使模型能够根据当前计划项预算选择下一步或申请重新规划。
