# 第 70 阶段：GPUI 诊断输入

本阶段使用 `gpui-component` 的 GPUI 原生多行输入控件，提供焦点、选区、剪贴板和输入法支持。组件版本固定为 `0.5.1`，并与项目使用的 `gpui 0.2.2` 兼容。

控制台增加「DIAGNOSIS BRIEF」区域。服务已连接时，可输入故障描述并点击「准备诊断」。也可以使用 `⌘↵` 准备诊断。输入内容会去除首尾留白，不能为空，且最多为 4000 个字符，与后端 `user_query` 字段限制保持一致。

本阶段不会发送 HTTP 请求，也不会调用模型、工具或 Harness。通过校验的描述只保存在本地界面状态，并显示为等待流式运行。后续阶段会将该描述发送到 `POST /api/v1/runs/stream`。
