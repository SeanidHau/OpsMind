# 第 62 阶段：显式运行回放 API

本阶段提供 `POST /api/v1/runs/{run_id}/replay`。接口返回指定归档运行的一份安全轨迹副本，用于工作台显式触发一次历史回放。

## 回放行为

接口使用缓存快照。请求不会调用模型、工具或 LangGraph 节点，也不会修改运行状态。响应包含运行 ID、回放模式、运行状态、事件数量和安全事件列表。事件字段与 `GET /api/v1/runs/{run_id}/trajectory` 一致。

接口不返回工具参数、工具原始观察结果、模型输入摘要或完整动作内容。

## 错误处理

未知 `run_id` 返回 `404` 和 `run not found`。应用未配置运行查询能力时，接口返回 `503` 和 `diagnosis run reader is not configured`。

## 持久化前置条件

当前 `RunArchive` 是同步接口，默认实现使用进程内存。持久化到 PostgreSQL 前，需要将归档、读取、审批决议和续跑链路整体迁移为异步 I/O，并在应用生命周期中管理数据库连接。不能在异步 Harness 中直接执行阻塞式数据库操作。
